IF YOU MANAGE THIS WEBSITE

Where do I put these fixes?

These settings normally belong on the web server, reverse proxy, hosting platform, or application configuration that sends the website's HTTP response. The exact location depends on how the website is hosted.

ApacheOften configured with server header rules or .htaccess.
NginxOften configured with add_header rules.
Cloud / hostingLook for HTTP response-header or security-header settings.
Web applicationSome frameworks and middleware can send these headers directly.

Important: Do not paste every example blindly. Make one change, test the website, then scan it again here.

IMPORTANT

This analyzer checks HTTP security headers only. A high score does not prove that a website is free from vulnerabilities, malware, insecure code, weak passwords, outdated software, or other security problems. A low score does not mean the website is hacked; it means this tool found missing or weak browser-level header protections.
